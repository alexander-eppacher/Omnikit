# 0003 – Lizenz: MIT

**Datum:** 24.10.2026

**Entscheidung:** Der eigene Code steht unter der MIT-Lizenz.

**Grund:** Einfache, weit verbreitete Lizenz. Eine eigene Vermarktung bleibt möglich; andere dürfen den Code aber ebenfalls frei nutzen, auch kommerziell. Abhängigkeiten müssen weiterhin kommerziell nutzbare Lizenzen haben (MIT, Apache-2.0, BSD); bei GPL/MPL wird vorher gefragt.
