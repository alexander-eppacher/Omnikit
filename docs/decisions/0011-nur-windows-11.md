# 0011 – Zielsystem nur Windows 11

**Datum:** 31.10.2026

**Entscheidung:** Omnikit unterstützt und testet nur noch **Windows 11**. Windows 10 22H2 fällt aus der Testmatrix.

**Grund:** Microsoft unterstützt Windows 10 nicht mehr; auch die verlängerten Sicherheitsupdates für Privatnutzer sind im Oktober 2026 ausgelaufen. Ein Wartungstool, das Geräte sicher halten soll, richtet sich deshalb an Windows 11. Die App kann unter Windows 10 weiterhin starten, Fehler dort werden aber nicht gezielt behoben.
